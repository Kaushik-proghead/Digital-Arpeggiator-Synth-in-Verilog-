Digital Arpeggiator Synth in Verilog 

This project is a small hardware-style audio synthesizer written entirely in Verilog. It uses a DDS oscillator, a custom sine ROM, an ADSR envelope, and a simple arpeggiator FSM to generate real audio that can be exported as a WAV file and played in any DAW. The goal was to explore how musical structure, timing and wave-generation can be done inside a digital logic environment. The arpeggio patterns, wave shaping, and envelopes are all tweakable, so we can experiment with different guitar-like tones and sequences. Everything runs in simulation using Icarus Verilog, with the testbench capturing samples and writing them into a standard WAV file.
